# Le site en deux langues (FR + EN)

Le français reste à la racine, inchangé : aucune URL existante ne bouge. L'anglais s'ajoute sous
`/en/`, avec ses propres slugs. Pas d'`i18n` natif d'Astro (comme sur beryldesign.fr) : la langue
d'une page se lit dans son chemin (`localeFromPath`, `src/lib/i18n.ts`).

## Où vit quoi

| Quoi | Français | Anglais |
|---|---|---|
| Libellés de l'interface (nav, footer, boutons, 404, sélecteur) | `UI` de `src/lib/i18n.ts` | même entrée, clé `en` |
| Chemins des pages fixes (blog, contact, légales…) | `PATHS` de `src/lib/i18n.ts` | idem |
| Pages à blocs | `src/content/pages/<slug>.md` → `/<slug>/` | `src/content/pages/en/<slug>.md` → `/en/<slug>/` |
| Accueil | `pages/home.md` → `/` | `pages/en/home.md` → `/en/` |
| Articles | `src/content/articles/<slug>.md` → `/blog/<slug>/` | `src/content/articles-en/<slug>.md` → `/en/blog/<slug>/` |
| Contact, 404 | `ContactView` / `NotFoundView` avec `locale="fr"` | les mêmes, `locale="en"` |
| RSS | `/rss.xml` | `/en/rss.xml` |
| Écrans du jeu (téléphones de la home) | `src/data/game.json` | `src/data/game.i18n.json` (voir plus bas) |

Une page anglaise nomme sa page française dans `translationOf` (premier champ du frontmatter) :
c'est ce qui relie les deux versions pour le hreflang, le sélecteur de langue et la suggestion
de langue. Une page anglaise sans `translationOf` (page d'atterrissage d'une campagne, par
exemple) vit seule : le sélecteur renvoie alors à l'accueil de l'autre langue.

## Articles

Un article anglais ne porte que son texte : `translationOf`, `title`, `description`, `faq`, et
le corps. Date, auteur, tags, image, icône et brouillon viennent de l'article français
(`src/lib/articles.ts`) : les deux versions paraissent ensemble, à la date du français. Un
article anglais peut rester en `draft: true` tout seul ; l'inverse n'existe pas (pas d'anglais
publié sans son français). Un `translationOf` qui ne correspond à aucun article fait échouer le
build.

Pour traduire un article : garder la même structure (titres, listes, liens, FAQ), réécrire les
liens internes vers leurs slugs anglais (`/en/blog/<slug-anglais>/`), garder tels quels les
liens vers play.dynastynova.com (UTM compris) et les chemins d'images. Les noms du jeu sont ceux
du jeu anglais, sauf les vaisseaux : le jeu anglais les affiche encore en français, on garde
donc le nom français avec une glose anglaise à la première mention (« the Récupérateur (the
recycler) »). Pas de « », ni d'espace avant `: ; ! ?`.

## Référencement

- hreflang `fr`, `en` et `x-default` uniquement quand les deux versions existent et sont
  indexables (`SEO.astro`) ; `x-default` pointe sur l'anglais (`X_DEFAULT_LOCALE`), la langue
  que comprennent les visiteurs d'ailleurs.
- `<html lang>`, `og:locale` / `og:locale:alternate` et `inLanguage` des JSON-LD suivent la page.
- Sitemap : les articles anglais prennent la date du français ; les pages `index: false` (FR et
  EN) et `/en/404/` en sont exclues (`astro.config.mjs`).

## Sélecteur et suggestion de langue

- `LanguageSwitch.astro` (en-tête, bureau et mobile) : mène à la même page dans l'autre langue,
  ou à l'accueil quand elle n'a pas de traduction. Le choix est retenu dans `localStorage`
  (`dn_lang`).
- `LanguageSuggest.astro` : un encart discret, écrit dans la langue proposée, quand le navigateur
  préfère l'autre langue et que la page existe dans cette langue. Jamais de redirection ; fermer
  l'encart ou utiliser le sélecteur vaut choix, il ne revient plus.

## Écrans du jeu

Les écrans reconstruits disent ce que dit le jeu, dans sa langue. `npm run game:sync` écrit le
catalogue français (`game.json`, images comprises) et `game.i18n.json` : les textes du jeu
anglais par code (bâtiments, défenses, recherches, packs, dynasties, avatars, navigation) et les
libellés d'interface empruntés au jeu, dans chaque langue.

- Un composant lit les entités dans la langue de la page : `gameFor(locale).pick(…)`.
- Un libellé du jeu se demande par sa clé, comme dans le jeu : `gameT(locale, 'pages/building:available')`.
  La synchro relève toutes les clés demandées dans `src/` : après en avoir ajouté une, lancer
  `npm run game:sync -- --texts` (textes seuls, au commit du catalogue en place, sans toucher aux
  images).
- Ce que le jeu anglais affiche en français (noms et descriptions des vaisseaux, descriptions des
  ressources, quelques boutons écrits en dur) reste en français sur le site anglais. Pour le
  corriger, le traduire dans le jeu, puis resynchroniser.
- Les biomes du sélecteur de planète n'ont pas de nom dans les fichiers de langue du jeu : leurs libellés sont dans
  `UI` (`biome.*`).
