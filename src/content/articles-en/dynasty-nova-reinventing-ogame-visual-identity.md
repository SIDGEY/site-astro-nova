## Introduction

Growing up with a cult classic like OGame makes you want to see it evolve. That nostalgia, combined with modern expectations, gave birth to the Dynasty Nova project: a tribute that comes into its own through a meticulous visual overhaul, combining UX design, art direction and technology.

## Context: from a degraded mobile version to a visual rebirth

OGame on mobile had become “a watered-down, compressed and less immersive version.” That disappointment set off the creation of Dynasty Nova as a mobile-first alternative that prioritizes usability, clarity and aesthetics, with no compromise.

## Upscaling the base visuals

The original assets, limited to 200×200 pixels, needed a multi-step enhancement:
- **Upscayl** for an initial 8× enlargement
- **Krea (Enhancer)** to preserve detail while keeping the result original
- **Freepik Upscaler** to produce usable visuals at 2048×2048

The images were then optimized for the web with TinyPNG compression and WebP conversion, keeping file sizes small with no loss of quality.

## Creating a “close but original” style

The challenge was to keep OGame's visual lineage without reproducing its assets. The strategy included:
- Generating a custom style with KREA from about twenty upscaled images
- An AI analysis synthesizing an independently inspired space-themed visual language
- Visual generation from descriptive prompts that never mention the original terms

The result: a coherent, consistent, recognizable universe that is distinctly Dynasty Nova's own.

## Generating the missing visuals

Elements that didn't exist yet (the shop, new buildings) called for co-creation with AI: prompts generated from an analysis of the code, the style applied, then a final upscale for consistency.

## Lighter files, no sacrifice: the WebP strategy

Every approved visual went through the same systematic treatment: WebP conversion, multi-resolution versions for mobile screens and lossless compression, which optimizes loading times and keeps everything smooth even on a poor network connection.

## A visual identity that defines Dynasty Nova

This graphic work created a lasting visual identity, thanks to an “elegant, almost cinematic” style and a mobile-first interface design. A Figma design system with modular, iterative and adaptable components ensures cohesion, scalability and an optimized player experience.

## Conclusion

Dynasty Nova goes beyond tribute: it's a reinvention. Drawing on contemporary tools (generative AI, upscaling, compression, design systems), this solo project successfully modernizes a beloved game while building a visual universe all its own: “One foot in nostalgia, the other in innovation.”
