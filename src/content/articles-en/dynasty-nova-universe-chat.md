## Introduction

Dynasty Nova now includes live chat, available from the side menu through the Messages screen. Three channels share one tabbed screen: the general universe chat, the alliance chat and private conversations between players.

## One tabbed screen for three ways to talk

### General chat, locked alliance chat, private messages

General chat brings together every player in the same universe. The alliance channel already exists in the interface but stays locked on the server side, since there is no alliance structure to attach it to yet. Private conversations group the history by contact, with an unread-messages badge in the side menu.

### Live, not refreshed every x seconds

Every message arrives through a real-time stream: no chat screen reloads at regular intervals. A general message only reloads the channels involved, and a private conversation only reloads the threads involved, which keeps the interface responsive even under heavy activity.

## Pinging a player with @

### Autocomplete that makes no false promises

Typing @ opens username autocomplete, which you can navigate with the keyboard. Only mentions the server actually recognizes are highlighted in the displayed message: a misspelled mention stays plain text rather than hinting at a notification that will never arrive. A mention of your own name stands out more than the others, because it's the only one that actually alerts you.

## Moderation that explains itself

### A rejected message shows up instead of vanishing

A message rejected by moderation (too long, external link, banned word) shows above the input box with the reason for the refusal, without clearing the rest of the conversation. External links are always refused, rather than checked case by case against a blocklist.

### Blocking a player, both ways

Any player can block another player, for private messages only; general chat is unaffected. The block works both ways: whether you blocked someone or they blocked you, sending a private message fails.

## Conclusion

Universe chat opens a social channel Dynasty Nova didn't have yet: talking to other commanders live, without leaving the galaxy or waiting for a page refresh. Alliances will join the conversation as soon as their structure exists in the game.
