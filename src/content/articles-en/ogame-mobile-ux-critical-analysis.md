## Introduction: a classic revisited for the mobile era

The article opens with OGame's nostalgic appeal for longtime players. The original desktop version offered “a clear interface that made it easy to get immersed in the game,” despite its minimalist look. Players appreciated the gradual learning curve, which let them master complex concepts (resources, technologies, fleets) step by step while keeping the game accessible.

## Background: a usability problem

The mobile adaptation gives up a great deal of usability. The interface suffers from “cramped menus, hard-to-read text and buttons placed too close together,” which hurts both readability and the smoothness of interactions. The lack of responsiveness across screen sizes creates inconsistent experiences, while the “one size fits all” approach shows a disregard for the diversity of mobile users.

## Degraded visuals

The graphics adaptation failed to take advantage of what mobile devices can do. Images look “blurry, stretched or poorly fitted,” breaking immersion. Animations that are smooth on desktop become “choppy on mobile,” creating a sense of slowness and obsolescence that is especially problematic during space battles, where visual precision has strategic importance.

## How the project began: from disappointment to ambition

Dynasty Nova was born in response to these shortcomings. Rather than copying OGame, the development team set out to modernize it, through in-depth research into mobile player behavior and UX best practices for strategy games.

### Design system

The project uses “a design system built in Figma with icons unified through the Phosphor library,” ensuring consistency across the whole user experience.

### Performance technologies

- **Tailwind CSS** for fast implementation and flexibility
- **AI asset optimization** (Upscayl, Krea, Freepik) for strong mobile performance
- **React** for a responsive architecture
- **RESTful APIs** to manage game data

## Conclusion

Dynasty Nova reflects “two sets of high standards: those of a frustrated user and of a designer convinced that UX must remain central to digital projects.” Building on modern web technologies and UX best practices, it aims to deliver a strategy game that honors the essence of OGame while fitting seamlessly into the way people use mobile devices today.
